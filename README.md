sshm 已采用 MIT 许可证开源。源码、问题反馈、安装脚本和新版本发布统一在 [qmtdlt/sshm](https://github.com/qmtdlt/sshm) 维护。

- [项目介绍与源码](https://github.com/qmtdlt/sshm)
- [版本下载](https://github.com/qmtdlt/sshm/releases)
- [Linux 安装说明](https://github.com/qmtdlt/sshm/blob/main/docs/linux-installation.md)

```sh
curl -fsSL https://raw.githubusercontent.com/qmtdlt/sshm/main/install.sh | sh
```

本仓库停止发布新版本，仅保留历史 Release 和旧安装命令的兼容入口。此处的 install.sh 已切换到主仓库下载源，并继续使用相同的签名验证公钥；原有下载链接仍可访问。
